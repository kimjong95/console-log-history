투자 글을 공개적으로 쓰기로 하면서 가장 먼저 확인한 건 수익률이 아니라 규정이었다.

국내에서 불특정 다수를 대상으로 한 투자 조언은 유사투자자문업 신고 대상이 될 수 있다. 그래서 모든 투자 글에 면책 문구를 고정하고, 직접적인 매수 추천 표현은 쓰지 않기로 했다.

## 사람이 기억하는 규칙은 언젠가 깨진다

문제는 "매번 잊지 않고 넣기"가 규칙으로서 약하다는 점이다. 글이 스무 편쯤 쌓이고 급하게 하나 올리는 날, 빠지는 건 늘 이런 것이다.

그래서 Content Collections 스키마에 조건부 필수로 넣었다.

```ts
.superRefine((data, ctx) => {
	if (data.category === 'invest' && !data.disclaimer?.trim()) {
		ctx.addIssue({ code: z.ZodIssueCode.custom, path: ['disclaimer'], message: '...' });
	}
})
```

이제 면책 문구가 없는 투자 글은 배포가 아니라 빌드에서 멈춘다. 규칙을 지키는 주체가 나에서 빌드로 옮겨갔다.
